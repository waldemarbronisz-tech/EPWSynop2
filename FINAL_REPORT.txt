ARCHITECTURE SUMMARY:
The EPW Synoptic Editor is built using Python 3 and PySide6. It features a robust model-view architecture using `QGraphicsScene` and `QGraphicsView` for the main engineering canvas. The system relies heavily on `dataclasses` to cleanly model domain objects (`EngineeringObject`, `Connection`, `Port`, `Project`, `Page`). A central `SymbolRegistry` defines behavior, limits, and supported domains for dynamically instantiated widgets.

DIRECTORY STRUCTURE:
epwsynoptic/
├── core/         # Core models, symbol registry, undo stack commands, serialization
├── examples/     # Procedurally generated demo projects
├── graphics/     # Scene, View, and schematic representation Items
├── runtime/      # Mock Runtime client, abstract interface for tags
├── symbols/      # Domain specific symbol definitions (Electrical, Water, HVAC)
├── ui/           # Dock widgets, inspector, property panels, tag explorer
└── tests/        # Pytest cases

MAIN IMPLEMENTED SYSTEMS:
1. Complete UI Layout with modular docks matching classic retro aesthetics.
2. Functional Symbol Library with a Symbol Preview dock.
3. Central Symbol Registry with correctly categorized, technical schematic components.
4. Drag-and-drop placement from Library -> Preview -> Canvas.
5. Port compatibility and type-inferred drag-to-connect interactions.
6. Orthogonal auto-routing logic.
7. Dynamic Busbar Taps: Engineers can draw connection lines from or to any fractional position along a thin busbar.
8. Label Engine providing configurable designations and names.
9. Full Page management and Tag Explorer (ELA/ADA/EPM data modeling).
10. Tag Binding allowing dragging tags directly onto symbols.
11. Preview mode with mock Command Generation and state toggle visualizations.
12. Reliable `.epwsyn` JSON serialization.
13. `QUndoStack` integration.
